Podstawy Javy

Java 8–21 Poziom: Początkujący

Historia Javy

Java powstała w Sun Microsystems w 1991 roku. James Gosling zaprojektował język z myślą o urządzeniach wbudowanych, jednak prawdziwą popularność zyskał dzięki przeglądarkom internetowym. Oficjalna premiera odbyła się w 1995 roku z hasłem przewodnim "Write Once, Run Anywhere".

RokWersjaKluczowe zmiany
1995Java 1.0Pierwsza publiczna wersja
2004Java 5Generics, Annotations, Autoboxing, for-each
2014Java 8 (LTS)Lambdy, Stream API, Optional, Date/Time API
2017Java 9Moduły JPMS, JShell
2021Java 17 (LTS)Sealed classes, Records (stable), Pattern Matching
2023Java 21 (LTS)Virtual Threads, Sequenced Collections, Pattern Matching switch
💡
LTS (Long-Term Support) — wersje Java 8, 11, 17 i 21 są wersjami z długim wsparciem. W produkcji używaj zawsze wersji LTS.

Zmienne i Nazewnictwo

Java 
// Konwencje nazewnictwa Javy (camelCase)
int wiekUzytkownika = 25;          // zmienna — camelCase
final int MAX_ROZMIAR = 100;       // stała — UPPER_SNAKE_CASE
String imieNazwisko = "Jan Kowalski";

// var — inferencja typów (Java 10+)
var lista = new ArrayList<String>(); // kompilator wie, że to ArrayList
var liczba = 42;                    // int

// Typ String — specjalny, niemutowalny obiekt
String a = "Hello";
String b = "Hello";
System.out.println(a == b);        // true (string pool)
System.out.println(a.equals(b));   // true — zawsze używaj equals()!

String c = new String("Hello");
System.out.println(a == c);        // false — różne obiekty w pamięci
System.out.println(a.equals(c));   // true — equals porównuje treść

Operatory

Struktura Pierwszego Programu

public class HelloWorld {

    public static void main(String[] args) {

Records — Nowoczesne Klasy Danych (Java 16+)

Record to specjalny rodzaj klasy przeznaczony do przechowywania niemutowalnych (immutable) danych. Kompilator automatycznie generuje konstruktor, gettery, equals(), hashCode() i toString().

Java 16+ 
// Jeden wiersz zastępuje 30+ linii tradycyjnej klasy
public record Punkt(double x, double y) {}

// Użycie
Punkt p = new Punkt(3.0, 4.0);
System.out.println(p.x());       // 3.0
System.out.println(p.y());       // 4.0
System.out.println(p);           // Punkt[x=3.0, y=4.0]

// Record z walidacją — kompaktowy konstruktor
public record Osoba(String imie, int wiek) {
    public Osoba {
        if (imie == null || imie.isBlank())
            throw new IllegalArgumentException("Imię nie może być puste");
        if (wiek < 0 || wiek > 150)
            throw new IllegalArgumentException("Nieprawidłowy wiek: " + wiek);
    }

    // Własne metody w recordzie
    public boolean czyPelnoletni() {
        return wiek >= 18;
    }
}
✅
Kiedy używać Records? Idealne dla DTO (Data Transfer Objects), value objects, wyników metod, odpowiedzi API. Wszędzie tam, gdzie potrzebujesz prostego kontenera danych bez logiki mutacji.
