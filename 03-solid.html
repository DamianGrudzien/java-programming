Zasady SOLID

Pięć fundamentalnych zasad projektowania obiektowego autorstwa Roberta C. Martina ("Uncle Bob"). Stosowanie SOLID prowadzi do kodu łatwego w utrzymaniu, testowaniu i rozszerzaniu.

5 zasad Poziom: Średnio­zaawansowany
📚
Źródło: Zasady SOLID opisane przez Roberta C. Martina, szeroko udokumentowane przez FreeCodeCamp, Baeldung i HowToDoInJava. Wielokrotnie zweryfikowane — spójne we wszystkich źródłach.
S
Single Responsibility Principle
Zasada Jednej Odpowiedzialności

Klasa powinna mieć tylko jeden powód do zmiany — jedną odpowiedzialność. Jeśli klasa obsługuje logikę biznesową i jednocześnie zapis do pliku, ma dwa powody do zmiany.

Źle
public class Raport {
    // ❌ Ta klasa robi ZA DUŻO
    public String generujTresc() { /* logika danych */ }
    public void zapiszDoBazy() { /* SQL — inny powód zmiany */ }
    public void wyslijEmailem(String adres) { /* SMTP — kolejny */ }
    public String formatujHTML() { /* prezentacja — jeszcze inny */ }
}
Dobrze
// ✅ Każda klasa = jedna odpowiedzialność
public class Raport {
    public String generujTresc() { /* tylko logika treści */ }
}

public class RaportRepository {
    public void zapisz(Raport r) { /* tylko zapis do bazy */ }
}

public class RaportMailer {
    public void wyslij(Raport r, String adres) { /* email */ }
}

public class RaportHtmlFormatter {
    public String format(Raport r) { /* HTML */ }
}
O
Open/Closed Principle
Zasada Otwarte / Zamknięte

Klasy powinny być otwarte na rozszerzanie, ale zamknięte na modyfikację. Nową funkcjonalność dodajemy przez nowe klasy, nie przez edycję istniejących.

Open/Closed
public interface Ksztalt {
    double obliczPole();
}

public class Kolo implements Ksztalt {
    private final double promien;
    @Override
    public double obliczPole() { return Math.PI * promien * promien; }
}

public class Prostokat implements Ksztalt {
    private final double szerokosc, wysokosc;
    @Override
    public double obliczPole() { return szerokosc * wysokosc; }
}

// KalkulatorPola NIGDY nie zmienia się gdy dodajemy nowy kształt!
public class KalkulatorPola {
    public double sumaPol(List<Ksztalt> ksztalty) {
        return ksztalty.stream()
            .mapToDouble(Ksztalt::obliczPole).sum();
    }
}
L
Liskov Substitution Principle
Zasada Podstawienia Liskov

Obiekty klasy podrzędnej powinny być wymienne z obiektami klasy bazowej bez naruszania poprawności programu.

❌
Klasyczny błąd LSP — Kwadrat rozszerza Prostokąt: Kwadrat jest prostokątem matematycznie, ale nie w sensie OOP.
LSP — poprawne
// ✅ Rozdziel Ptaka i zdolność latania
public abstract class Ptak {
    public abstract void jedz();
    public abstract void spij();
}

public interface Latajacy {
    void lec();
}

public class Wrobel extends Ptak implements Latajacy {
    public void jedz() { }
    public void spij() { }
    public void lec() { System.out.println("Wróbel leci"); }
}

public class Pingwin extends Ptak {
    public void jedz() { }
    public void spij() { }
}
I
Interface Segregation Principle
Zasada Segregacji Interfejsów

Klienci nie powinni być zmuszani do implementacji metod, których nie używają.

ISP
// ✅ Małe interfejsy
public interface Drukarka   { void drukuj(); }
public interface Skaner     { void skanuj(); }
public interface Faks       { void faksuj(); }

public class ProstaDrukarka implements Drukarka {
    @Override
    public void drukuj() { System.out.println("Drukuję..."); }
}

public class WielofunkcyjneUrządzenie implements Drukarka, Skaner, Faks {
    public void drukuj() { }
    public void skanuj() { }
    public void faksuj() { }
}
D
Dependency Inversion Principle
Zasada Odwrócenia Zależności

Moduły wysokopoziomowe nie powinny zależeć od niskopoziomowych — oboje powinny zależeć od abstrakcji.

DIP + Dependency Injection
public interface NotyfikacjaSerwis {
    void wyslij(String wiadomosc);
}

public class EmailSerwis implements NotyfikacjaSerwis {
    public void wyslij(String msg) { /* SMTP */ }
}

public class ZamowienieSerwis {
    private final NotyfikacjaSerwis notyfikacja;

    public ZamowienieSerwis(NotyfikacjaSerwis notyfikacja) {
        this.notyfikacja = notyfikacja;
    }

    public void potwierdzZamowienie(String nr) {
        notyfikacja.wyslij("Zamówienie " + nr + " potwierdzone");
    }
}
