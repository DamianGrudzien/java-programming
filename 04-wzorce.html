Wzorce Projektowe

Sprawdzone rozwiązania typowych problemów projektowych. Podzielone na trzy grupy: kreacyjne (jak tworzyć obiekty), strukturalne (jak je łączyć) i behawioralne (jak komunikują się obiekty).

Singleton

Gwarantuje jedną instancję klasy w całej aplikacji. Najlepiej implementować przez enum — automatycznie thread-safe, odporna na deserialization.

Singleton (Enum — najlepsza metoda)
// ✅ Enum Singleton — rekomendacja Effective Java (Bloch)
public enum AppConfig {
    INSTANCE;

    private final String dbUrl = "jdbc:postgresql://localhost/mydb";
    private int timeout = 30;

    public String getDbUrl() { return dbUrl; }
    public int    getTimeout() { return timeout; }
}

// Użycie
String url = AppConfig.INSTANCE.getDbUrl();

Builder

Oddziela budowanie złożonego obiektu od jego reprezentacji. Idealne gdy klasa ma wiele opcjonalnych parametrów — eliminuje "telescoping constructors".

Builder Pattern
public class Zapytanie {
    private final String tabela;
    private final String warunek;
    private final int    limit;
    private final int    offset;

    private Zapytanie(Builder b) {
        tabela   = b.tabela; warunek = b.warunek;
        limit    = b.limit;  offset  = b.offset;
    }

    public static class Builder {
        private final String tabela;   // wymagane
        private String warunek = "";   // opcjonalne
        private int    limit   = 100;
        private int    offset  = 0;

        public Builder(String tabela) { this.tabela = tabela; }

        public Builder gdzie(String w) { warunek = w; return this; }
        public Builder limit(int l)    { limit   = l; return this; }
        public Builder offset(int o)   { offset  = o; return this; }
        public Zapytanie buduj()        { return new Zapytanie(this); }
    }
}

// Czytelne, płynne API
Zapytanie q = new Zapytanie.Builder("uzytkownicy")
    .gdzie("wiek > 18")
    .limit(50)
    .offset(100)
    .buduj();

Factory Method

Factory
public interface Platnosc { void przetworz(double kwota); }
public class PlatnoscKarta  implements Platnosc { public void przetworz(double k) { /*karta*/ } }
public class PlatnoscBlik   implements Platnosc { public void przetworz(double k) { /*BLIK*/  } }
public class PlatnoscPrzelewimplements Platnosc { public void przetworz(double k) { /*przelew*/} }

public class PlatnoscFabryka {
    public static Platnosc stworz(String typ) {
        return switch (typ.toUpperCase()) {
            case "KARTA"   -> new PlatnoscKarta();
            case "BLIK"    -> new PlatnoscBlik();
            case "PRZELEW" -> new PlatnoscPrzelew();
            default -> throw new IllegalArgumentException("Nieznana metoda: " + typ);
        };
    }
}

// Klient nie zna konkretnych klas!
Platnosc p = PlatnoscFabryka.stworz("BLIK");
p.przetworz(149.99);

Adapter

Umożliwia współpracę klas o niekompatybilnych interfejsach — "tłumaczy" między nimi. Przydatny przy integracji z zewnętrznymi bibliotekami.

Adapter
// Nasz interfejs (nowy system)
public interface Logger {
    void log(String poziom, String wiadomosc);
}

// Zewnętrzna biblioteka (nie możemy jej zmienić)
public class StaraAplikacjaLogger {
    public void pisz(int kod, String tekst) { /* stary format */ }
}

// Adapter "tłumaczy" między interfejsami
public class LoggerAdapter implements Logger {
    private final StaraAplikacjaLogger stary;

    public LoggerAdapter(StaraAplikacjaLogger s) { this.stary = s; }

    @Override
    public void log(String poziom, String wiadomosc) {
        int kod = poziom.equals("ERROR") ? 3 : poziom.equals("WARN") ? 2 : 1;
        stary.pisz(kod, wiadomosc);
    }
}

Decorator

Dynamicznie opakowuje obiekt i dodaje mu nową funkcjonalność bez modyfikacji. Java I/O jest klasycznym przykładem: new BufferedReader(new FileReader(...)).

Decorator
public interface TextProcessor { String process(String text); }

public class PlainProcessor implements TextProcessor {
    public String process(String t) { return t; }
}

public class TrimDecorator implements TextProcessor {
    private final TextProcessor wrapped;
    public TrimDecorator(TextProcessor w) { wrapped = w; }
    public String process(String t) { return wrapped.process(t).trim(); }
}

public class UpperCaseDecorator implements TextProcessor {
    private final TextProcessor wrapped;
    public UpperCaseDecorator(TextProcessor w) { wrapped = w; }
    public String process(String t) { return wrapped.process(t).toUpperCase(); }
}

// Nakładanie dekoratorów — jak cebula
TextProcessor proc = new UpperCaseDecorator(
    new TrimDecorator(
        new PlainProcessor()
    )
);
System.out.println(proc.process("  hello world  ")); // "HELLO WORLD"

Observer

Definiuje zależność jeden-do-wielu. Gdy obiekt zmienia stan, wszyscy zarejestrowani obserwatorzy są powiadamiani. Fundament systemów event-driven.

Observer
public interface Obserwator<T> {
    void onZdarzenie(T zdarzenie);
}

public class MagazynZdarzen<T> {
    private final List<Obserwator<T>> obs = new ArrayList<>();

    public void subscribe(Obserwator<T> o)   { obs.add(o); }
    public void unsubscribe(Obserwator<T> o) { obs.remove(o); }
    public void publish(T zdarzenie) {
        obs.forEach(o -> o.onZdarzenie(zdarzenie));
    }
}

// Lambdy jako obserwatorzy (Java 8+)
var bus = new MagazynZdarzen<String>();
bus.subscribe(e -> System.out.println("📧 Email o: " + e));
bus.subscribe(e -> System.out.println("📱 SMS o: " + e));
bus.publish("Nowe zamówienie #42");

Strategy

Definiuje rodzinę wymiennych algorytmów. Klient wybiera strategię w czasie działania bez zmiany własnego kodu.

Strategy
// W Java 8+ strategia = interfejs funkcyjny
@FunctionalInterface
public interface StrategiaRabatuInterface {
    double obliczCene(double cena);
}

public class KoszykZakupow {
    private StrategiaRabatuInterface strategia;

    public void ustawStrategię(StrategiaRabatuInterface s) { strategia = s; }

    public double obliczFinalnaKwote(double cena) {
        return strategia.obliczCene(cena);
    }
}

// Strategie jako lambdy — zero klas!
var koszyk = new KoszykZakupow();
koszyk.ustawStrategię(cena -> cena * 0.9); // 10% rabat
System.out.println(koszyk.obliczFinalnaKwote(100.0)); // 90.0

koszyk.ustawStrategię(cena -> cena > 500 ? cena * 0.8 : cena); // 20% dla dużych
