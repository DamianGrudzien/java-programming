Kolekcje & Generics

Java Collections Framework — gotowe implementacje struktur danych. Wybór właściwej kolekcji drastycznie wpływa na wydajność aplikacji.

Java 8–21 Poziom: Podstawowy
💡
Złota zasada: Zawsze deklaruj zmienną przez interfejs. List<String> lista = new ArrayList<>(); ✅

List — Listy

KlasaDostęp O(?)Wstawianie O(?)Kiedy używać
ArrayListO(1)O(n) w środkuDomyślny wybór. Szybki dostęp indeksem.
LinkedListO(n)O(1) na krańcachGdy często dodajesz/usuwasz na początku/końcu.
CopyOnWriteArrayListO(1)O(n)Wielowątkowe scenariusze z częstym czytaniem.
List — dobre praktyki
// Niemodyfikowalna lista (Java 9+)
List<String> kolory = List.of("czerwony", "zielony", "niebieski");

// Mutowalana lista ze wstępnymi elementami
List<Integer> liczby = new ArrayList<>(List.of(1, 2, 3));
liczby.add(4);
liczby.remove(Integer.valueOf(2)); // usuwa wartość 2, nie indeks!

Map — Mapy klucz-wartość

KlasaZłożonośćKolejnośćKiedy używać
HashMapO(1)BrakDomyślny wybór. Najszybszy.
LinkedHashMapO(1)WstawianiaGdy potrzebujesz pamiętać kolejność.
TreeMapO(log n)Naturalna kluczyGdy potrzebujesz posortowanych kluczy.
ConcurrentHashMapO(1)BrakBezpieczna wielowątkowo.
Map — nowoczesne metody
Map<String, Integer> licznik = new HashMap<>();

// merge — eleganckie zliczanie (Java 8+)
String[] slowa = {"java", "java", "python"};
for (String s : slowa) {
    licznik.merge(s, 1, Integer::sum);
}

// getOrDefault — bezpieczne pobieranie
int ile = licznik.getOrDefault("kotlin", 0);

// Niemodyfikowalna mapa (Java 9+)
Map<String, Integer> kody = Map.of("HTTP_OK", 200, "NOT_FOUND", 404);

Generics — Typy Generyczne

Generics
public class Para<A, B> {
    private final A pierwszy;
    private final B drugi;

    public Para(A a, B b) { pierwszy=a; drugi=b; }
    public A pierwszy() { return pierwszy; }
    public B drugi()    { return drugi; }

    public static <A, B> Para<A, B> of(A a, B b) {
        return new Para<>(a, b);
    }
}

// Bounded wildcards — Producer Extends, Consumer Super (PECS)
public double sumujLiczby(List<? extends Number> lista) {
    return lista.stream().mapToDouble(Number::doubleValue).sum();
}

public void dodajLiczby(List<? super Integer> lista) {
    lista.add(1); lista.add(2); lista.add(3);
}
