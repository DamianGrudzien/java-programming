Spring Boot

Spring Boot eliminuje boilerplate konfiguracji i pozwala zbudować produkcyjną aplikację REST w minutach. Auto-configuration, embedded server, Actuator — wszystko gotowe od razu.

Spring Boot 3 Java 21 Poziom: Średniozaawansowany

Startowy Projekt — Spring Initializr

Najszybszy start: start.spring.io — wybierasz zależności, pobierasz archiwum ZIP, importujesz do IDE. Struktura wygenerowanego projektu:

Struktura projektu Spring Boot 
src/main/java/com/example/sklep/
├── SklepApplication.java       # @SpringBootApplication — punkt wejścia
├── controller/
│   └── ProduktController.java  # REST endpoints
├── service/
│   └── ProduktSerwis.java      # logika biznesowa
├── repository/

    └── Produkt.java            # encja/DTO

src/main/resources/
└── application.properties          # konfiguracja
SklepApplication.java 
// @SpringBootApplication = @Configuration + @ComponentScan + @EnableAutoConfiguration
@SpringBootApplication
public class SklepApplication {
    public static void main(String[] args) {
        SpringApplication.run(SklepApplication.class, args);
        // ↑ uruchamia embedded Tomcat na porcie 8080
    }
}

REST Controller — Kompletny CRUD

ProduktController.java 
@RestController
@RequestMapping("/api/produkty")
@RequiredArgsConstructor  // Lombok — generuje constructor injection
public class ProduktController {

    private final ProduktSerwis serwis;

    // GET /api/produkty
    @GetMapping
    public List<ProduktDto> wszystkie() {
        return serwis.wszystkie();
    }

    // GET /api/produkty/42
    @GetMapping("/{id}")
    public ResponseEntity<ProduktDto> jeden(@PathVariable Long id) {
        return serwis.znajdz(id)
            .map(ResponseEntity::ok)
            .orElse(ResponseEntity.notFound().build());
    }

    // POST /api/produkty
    @PostMapping
    @ResponseStatus(HttpStatus.CREATED)
    public ProduktDto stworz(@RequestBody @Valid NowyProduktRequest req) {
        return serwis.stworz(req);
    }

    // PUT /api/produkty/42
    @PutMapping("/{id}")
    public ProduktDto aktualizuj(
            @PathVariable Long id,
            @RequestBody @Valid AktualizujProduktRequest req) {
        return serwis.aktualizuj(id, req);
    }

    // DELETE /api/produkty/42
    @DeleteMapping("/{id}")
    @ResponseStatus(HttpStatus.NO_CONTENT)
    public void usun(@PathVariable Long id) {
        serwis.usun(id);
    }
}

Walidacja — @Valid + Bean Validation

DTO z walidacją 
public record NowyProduktRequest(
    @NotBlank(message = "Nazwa nie może być pusta")
    @Size(min = 2, max = 100)
    String nazwa,

    @NotNull
    @Positive(message = "Cena musi być dodatnia")
    BigDecimal cena,

    @Min(0) @Max(9999)
    int stanMagazynowy,

    @Email
    String emailDostawcy
) {}

// Globalny handler błędów walidacji
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(MethodArgumentNotValidException.class)
    @ResponseStatus(HttpStatus.BAD_REQUEST)
    public Map<String, String> walidacjaError(MethodArgumentNotValidException ex) {
        return ex.getBindingResult()
            .getFieldErrors()
            .stream()
            .collect(Collectors.toMap(
                FieldError::getField,
                FieldError::getDefaultMessage
            ));
    }

    @ExceptionHandler(EntityNotFoundException.class)
    @ResponseStatus(HttpStatus.NOT_FOUND)
    public Map<String, String> notFound(EntityNotFoundException ex) {
        return Map.of("error", ex.getMessage());
    }
}

application.properties — Konfiguracja

.properties 
# Serwer
server.port=8080
server.servlet.context-path=/api

# Baza danych
spring.datasource.url=jdbc:postgresql://localhost:5432/sklep
spring.datasource.username=postgres
spring.datasource.password=${DB_PASSWORD}  # ze zmiennej środowiskowej!

# JPA
spring.jpa.hibernate.ddl-auto=validate
spring.jpa.show-sql=false

# Logowanie
logging.level.com.example=DEBUG
logging.level.org.springframework.web=INFO

# Własna konfiguracja
app.jwt.secret=${JWT_SECRET}
app.jwt.expiration=3600
.yml — czytelniejszy format 
server:
  port: 8080
  servlet:
    context-path: /api

spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/sklep
    username: postgres
    password: ${DB_PASSWORD}
  jpa:
    hibernate:
      ddl-auto: validate
    show-sql: false

logging:
  level:
    com.example: DEBUG

app:
  jwt:
    secret: ${JWT_SECRET}
    expiration: 3600

Actuator — Monitoring Aplikacji

Spring Boot Actuator udostępnia endpointy HTTP do monitorowania stanu aplikacji. Niezbędny w środowisku produkcyjnym i do integracji z Prometheus/Grafana.

Actuator — konfiguracja i endpointy 
# Włącz wybrane endpointy (domyślnie tylko /health i /info)
management.endpoints.web.exposure.include=health,info,metrics,env
management.endpoint.health.show-details=when-authorized

# Dostępne endpointy po konfiguracji:
# GET /actuator/health     → { "status": "UP" }
# GET /actuator/info       → informacje o aplikacji
# GET /actuator/metrics    → lista metryk
# GET /actuator/metrics/jvm.memory.used  → zużycie pamięci
# GET /actuator/env        → zmienne środowiskowe i properties
# GET /actuator/loggers    → poziomy logowania
💡
Profile Spring — uruchom aplikację z różnymi konfiguracjami: --spring.profiles.active=dev załaduje application-dev.properties. Idealne do separacji konfiguracji dev/test/prod.
