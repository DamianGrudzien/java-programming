## Uruchomienie lokalne

Strona jest statyczna — wy­starczy otworzyć `index.html` w prze­glądarce. Nie wymaga serwera ani build tools.

```bash
# np. przez Python
python3 -m http.server 8080
# lub przez Node
npx serve .
```

Następnie odwiedź `http://localhost:8080`.
