Streams, Lambdy
& Optional

Programowanie funkcyjne w Javie 8+. Stream API pozwala przetwarzać kolekcje deklaratywnie, zw ięźle i wydajnie.

Java 8+ Poziom: Średniozaawansowany

Wyrażenia Lambda

Lambda — ewolucja składni
// Przed Java 8 — anonimowa klasa
Comparator<String> comp1 = new Comparator<>() {
    public int compare(String a, String b) { return a.compareTo(b); }
};

// Java 8+ — lambda
Comparator<String> comp2 = (a, b) -> a.compareTo(b);

// Java 8+ — referencja do metody
Comparator<String> comp3 = String::compareTo;

// Wbudowane interfejsy funkcyjne
Predicate<String> czyDlugi = s -> s.length() > 5;
Function<String, Integer> dlugosc = String::length;
Consumer<String> drukuj = System.out::println;
Supplier<List<String>> nowaLista = ArrayList::new;

Pipeline Stream API

Stream to sekwencja elementów przetwarzana leniwie (lazy). Pipeline składa się z źródła, operacji pośrednich (map, filter, sorted) i jednej operacji terminalnej (collect, forEach, reduce).

Stream Pipeline
record Pracownik(String imie, String dzial, double pensja) {}

List<Pracownik> pracownicy = List.of(
    new Pracownik("Anna",  "IT", 8500),
    new Pracownik("Bartek","IT", 9200),
    new Pracownik("Celina","HR", 6100)
);

// Imiona pracowników IT posortowane malejąco po pensji
List<String> itNajlepsi = pracownicy.stream()
    .filter(p -> p.dzial().equals("IT"))
    .sorted(Comparator.comparingDouble(Pracownik::pensja).reversed())
    .map(Pracownik::imie)
    .toList();

// Grupowanie po dziale
Map<String, List<Pracownik>> poDziale = pracownicy.stream()
    .collect(Collectors.groupingBy(Pracownik::dzial));
⚠️
Stream można użyć tylko raz! Po operacji terminalnej stream jest wyczerpany. Aby wielokrotnie przetwarzać te same dane — użyj kolekcji lub utwórz nowy stream.

Collectors — Zbieranie Wyników

Collectors to fabryki strategii gromadzenia elementów strumienia. Collectors.toList() jest najczęstszy, ale możliwości jest znacznie więcej.

Collectors — przydatne metody
List<String> imiona = List.of("Anna", "Bartek", "Celina", "Bartek");

// toList / toSet / toUnmodifiableList
List<String> lista = imiona.stream().collect(Collectors.toList());
Set<String> unikalne = imiona.stream().collect(Collectors.toSet());

// joining — łączenie Stringów
String csv = imiona.stream()
    .collect(Collectors.joining(", ", "[", "]"));
// wynik: "[Anna, Bartek, Celina, Bartek]"

// groupingBy — grupowanie w Map
Map<Integer, List<String>> wgDlugosci = imiona.stream()
    .collect(Collectors.groupingBy(String::length));

// partitioningBy — podział na dwie grupy (true/false)
Map<Boolean, List<String>> podział = imiona.stream()
    .collect(Collectors.partitioningBy(s -> s.length() > 4));

// counting / summarizingDouble
Map<String, Long> liczbaPoKazdy = imiona.stream()
    .collect(Collectors.groupingBy(s -> s, Collectors.counting()));
// wynik: {Anna=1, Bartek=2, Celina=1}

flatMap i reduce

flatMap spłaszcza strumień strumieni — przydatny gdy każdy element produkuje kolekcję. reduce agreguje elementy do jednej wartości.

flatMap & reduce
// flatMap — lista list → jedna lista
List<List<String>> grupy = List.of(
    List.of("Anna", "Bartek"),
    List.of("Celina")
);
List<String> wszyscy = grupy.stream()
    .flatMap(Collection::stream)
    .toList();  // [Anna, Bartek, Celina]

// flatMap ze Stringów na słowa
List<String> zdania = List.of("hello world", "foo bar");
List<String> slowa = zdania.stream()
    .flatMap(s -> Arrays.stream(s.split(" ")))
    .toList();  // [hello, world, foo, bar]

// reduce — sumowanie
int suma = IntStream.rangeClosed(1, 10)
    .reduce(0, Integer::sum);  // 55

// reduce — najdłuższy String
Optional<String> najdluzszy = imiona.stream()
    .reduce((a, b) -> a.length() >= b.length() ? a : b);

// Skróty dla liczb: sum(), average(), min(), max()
double srednia = IntStream.of(1, 2, 3, 4).average().orElse(0);

Optional — eliminacja NullPointerException

Optional to kontener na wartość, która może być pusta. Zastępuje null jako sygnał braku wartości — zmuszając kod wywołujący do jawnej obsługi obu przypadków.

Optional — dobre praktyki
// ✅ Z Optional — bezpieczne i deklaratywne
Optional<Uzytkownik> opt = repo.znajdz(id);

opt.ifPresent(u -> System.out.println(u.getImie()));
String imie = opt.map(Uzytkownik::getImie).orElse("Anonim");
Uzytkownik u2 = opt.orElseThrow(
    () -> new EntityNotFoundException("id=" + id));

// ifPresentOrElse — Java 9+
opt.ifPresentOrElse(
    u -> System.out.println("Znaleziono: " + u.getImie()),
    () -> System.out.println("Brak użytkownika")
);

// ❌ Anty-wzorzec — pokonuje sens Optional
if (opt.isPresent()) { opt.get(); }  // to samo co if(x != null)
💡
Optional w zwracanych typach. Używaj Optional jako typ zwracany metody, nigdy jako typ pola klasy ani parametru metody. Nie opakowuj kolekcji w Optional — pusta lista jest lepsza niż Optional<List>.
