Streams, Lambdy
& Optional

Programowanie funkcyjne w Javie 8+. Stream API pozwala przetwarzać kolekcje deklaratywnie, zw ięźle i wydajnie.

Wyrażenia Lambda

Lambda — ewolucja składni
// Przed Java 8 — anonimowa klasa
Comparator<String> comp1 = new Comparator<>() {
    public int compare(String a, String b) { return a.compareTo(b); }
};

// Java 8+ — lambda
Comparator<String> comp2 = (a, b) -> a.compareTo(b);

// Java 8+ — referencja do metody
Comparator<String> comp3 = String::compareTo;

// Wbudowane interfejsy funkcyjne
Predicate<String> czyDlugi = s -> s.length() > 5;
Function<String, Integer> dlugosc = String::length;
Consumer<String> drukuj = System.out::println;
Supplier<List<String>> nowaLista = ArrayList::new;

Pipeline Stream API

Stream Pipeline
record Pracownik(String imie, String dzial, double pensja) {}

List<Pracownik> pracownicy = List.of(
    new Pracownik("Anna",  "IT", 8500),
    new Pracownik("Bartek","IT", 9200),
    new Pracownik("Celina","HR", 6100)
);

// Imiona pracowników IT posortowane malejąco po pensji
List<String> itNajlepsi = pracownicy.stream()
    .filter(p -> p.dzial().equals("IT"))
    .sorted(Comparator.comparingDouble(Pracownik::pensja).reversed())
    .map(Pracownik::imie)
    .toList();

// Grupowanie po dziale
Map<String, List<Pracownik>> poDziale = pracownicy.stream()
    .collect(Collectors.groupingBy(Pracownik::dzial));
⚠️
Stream można użyć tylko raz! Po operacji terminalnej stream jest wyczerpany.

Optional — eliminacja NullPointerException

Optional — dobre praktyki
// ✅ Z Optional — bezpieczne i deklaratywne
Optional<Uzytkownik> opt = repo.znajdz(id);

opt.ifPresent(u -> System.out.println(u.getImie()));
String imie = opt.map(Uzytkownik::getImie).orElse("Anonim");
Uzytkownik u2 = opt.orElseThrow(
    () -> new EntityNotFoundException("id=" + id));
