Maven & Gradle

Narzędzia budowania projektu — zarządzanie zależnościami, cykl życia buildu, struktura projektu. Maven to standard enterprise, Gradle dominuje w ekosystemie Android i Spring Boot.

Maven 3 Gradle 8 Poziom: Podstawowy

Maven — Struktura Projektu

Maven narzuca konwencję nad konfiguracją — standardową strukturę katalogów. Jeśli jej przestrzegasz, Maven „wie” gdzie szukać kodu, testów i zasobów.

Struktura katalogów Maven 
moj-projekt/
├── pom.xml                          # Konfiguracja projektu
├── src/
│   ├── main/
│   │   ├── java/                    # Kod źródłowy
│   │   │   └── com/example/
│   │   │       └── App.java
│   │   └── resources/               # Pliki konfiguracyjne, SQL, properties
│   │       └── application.properties
│   └── test/
│       ├── java/                    # Testy jednostkowe
│       │   └── com/example/
│       │       └── AppTest.java
│       └── resources/               # Zasoby testowe
└── target/                          # Wyniki budowania (generowane, nie do repo!)
    ├── classes/
    └── moj-projekt-1.0.jar

pom.xml — Serce Projektu Maven

pom.xml — kompletny przykład 
<project xmlns="http://maven.apache.org/POM/4.0.0">
    <modelVersion>4.0.0</modelVersion>

    <!-- Tożsamość projektu: groupId:artifactId:version = GAV -->
    <groupId>com.example</groupId>
    <artifactId>moj-projekt</artifactId>
    <version>1.0.0-SNAPSHOT</version>
    <packaging>jar</packaging>

    <properties>
        <java.version>21</java.version>
        <maven.compiler.source>${java.version}</maven.compiler.source>
        <maven.compiler.target>${java.version}</maven.compiler.target>
        <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
    </properties>

    <dependencies>
        <!-- Scope: compile (domyślny), test, provided, runtime -->
        <dependency>
            <groupId>org.junit.jupiter</groupId>
            <artifactId>junit-jupiter</artifactId>
            <version>5.10.2</version>
            <scope>test</scope>   <!-- tylko do testów -->
        </dependency>
        <dependency>
            <groupId>org.slf4j</groupId>
            <artifactId>slf4j-api</artifactId>
            <version>2.0.12</version>
            <!-- scope compile — dostępny wszędzie -->
        </dependency>
    </dependencies>
</project>

Cykl Życia Maven

FazaPolecenieCo robi
validateSprawdza poprawność pom.xml
compilemvn compileKompiluje kod źródłowy do target/classes
testmvn testUruchamia testy jednostkowe
packagemvn packagePakuje do JAR/WAR w target/
verifymvn verifyUruchamia testy integracyjne
installmvn installInstaluje JAR w lokalnym repozytorium (~/.m2)
deploymvn deployWysyła do zdalnego repozytorium (Nexus, Artifactory)
💡
Każda faza uruchamia wszystkie poprzednie. mvn package = validate + compile + test + package. Aby pominąć testy: mvn package -DskipTests.
Najczęstsze komendy Maven 
# Zbuduj i uruchom testy
mvn clean package

# Pominąć testy (szybszy build)
mvn clean package -DskipTests

# Uruchom tylko jeden test
mvn test -Dtest=NazwaKlasyTest

# Pokaż drzewo zależności (przydatne przy konfliktach)
mvn dependency:tree

# Sprawdź dostępne aktualizacje zależności
mvn versions:display-dependency-updates

# Uruchom aplikację (plugin exec)
mvn exec:java -Dexec.mainClass="com.example.App"

Gradle — Nowoczesna Alternatywa

Gradle używa skryptów (Groovy lub Kotlin DSL) zamiast XML. Jest szybszy dzięki inkrementalnemu buildowi i cache'owaniu. Domyślny w Spring Initializr i Android.

build.gradle.kts 
plugins {
    java
    application
}

group = "com.example"
version = "1.0.0"

java {
    sourceCompatibility = JavaVersion.VERSION_21
    targetCompatibility = JavaVersion.VERSION_21
}

repositories {
    mavenCentral()  // skąd pobierać zależności
}

dependencies {
    implementation("org.slf4j:slf4j-api:2.0.12")
    testImplementation("org.junit.jupiter:junit-jupiter:5.10.2")
    testRuntimeOnly("org.junit.platform:junit-platform-launcher")
}

application {
    mainClass = "com.example.App"
}

tasks.test {
    useJUnitPlatform()
}
build.gradle 
plugins {
    id 'java'
    id 'application'
}

group = 'com.example'
version = '1.0.0'

java {
    sourceCompatibility = JavaVersion.VERSION_21
}

repositories {
    mavenCentral()
}

dependencies {
    implementation 'org.slf4j:slf4j-api:2.0.12'
    testImplementation 'org.junit.jupiter:junit-jupiter:5.10.2'
}

application {
    mainClass = 'com.example.App'
}

test {
    useJUnitPlatform()
}
Najczęstsze komendy Gradle 
# Zbuduj projekt
./gradlew build

# Uruchom testy
./gradlew test

# Uruchom aplikację
./gradlew run

# Pokaż zależności
./gradlew dependencies

# Pokaż dostępne taski
./gradlew tasks

# Wyczyść build
./gradlew clean
