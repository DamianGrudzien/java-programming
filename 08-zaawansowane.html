Java 21 Poziom: Zaawansowany

Jak działa JVM

Pamięć JVM
Heap (sterta) — obiekty i tablice
├── Young Generation — nowe obiekty, szybkie GC
│   ├── Eden Space
│   ├── Survivor S0
│   └── Survivor S1
└── Old Generation — dłużojące, Major GC

Metaspace — metadane klas
Stack — ramki metod, zmienne lokalne (per thread)

java -XX:+UseG1GC -Xms512m -Xmx4g MyApp
java -XX:+UseZGC MyApp  // ultra-niskie latency

Clean Code — Zasady Czystego Kodu

Czysty kod to kod, który łatwo czytać, zmieniać i testować. Cztery konkretne zasady z przykładami refaktoringu.

🛑 Guard Clauses — Early Return
▼
Guard Clauses
// ❌ Głęboko zagnieżdżone warunki
if (user != null) {
    if (user.isActive()) {
        if (user.hasPermission("ADMIN")) {
            doSomething();
        }
    }
}

// ✅ Guard Clauses — wczesne wyjście
if (user == null) return;
if (!user.isActive()) return;
if (!user.hasPermission("ADMIN")) return;
doSomething();
📝 Małe metody i dobre nazwy
▼
Refaktoring metody
// ❌ Jedna duża metoda robi wszystko
public void process(Order o) {
    if (o.getItems().isEmpty()) throw new IllegalArgumentException("brak");
    double sum = 0;
    for (var item : o.getItems()) sum += item.getPrice() * item.getQty();
    if (sum > 1000) sum *= 0.9;
    o.setTotal(sum);
    emailService.send(o.getEmail(), "Zamówienie: " + sum);
}

// ✅ Małe, dobrze nazwane metody
public void processOrder(Order order) {
    validateOrder(order);
    order.setTotal(calculateTotal(order));
    sendConfirmation(order);
}

private double calculateTotal(Order order) {
    double sum = order.getItems().stream()
        .mapToDouble(i -> i.getPrice() * i.getQty())
        .sum();
    return sum > 1000 ? sum * 0.9 : sum;
}

    User user = db.find(email);
    auditLog.save("pobrano: " + email); // niespodzianka!
    return user;
}
